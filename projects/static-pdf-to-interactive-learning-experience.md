The Guide to Investing for Newcomers to Canada provides important information about banking, saving, investing, risk, and fraud prevention for individuals new to Canada. Currently, the guide is delivered as a PDF, requiring users to navigate a lengthy document to access information.

This concept redesign reimagines the guide as a dedicated web experience optimized for accessibility, mobile devices, and progressive learning.

<button class="cta-project-button"><a href="https://investor-guide-rs.netlify.app/">Explore the Guide on Netlify</a></button>

## Problem

The guide contains valuable educational content, but the PDF format presents challenges:

- Long-form scrolling and reading
- Limited navigation between topics
- Low engagement
- Content optimized for print rather than digital consumption
- Important concepts buried within document pages

For newcomers who may be unfamiliar with Canadian investing, the learning experience can feel overwhelming.

<hr>

## Purpose of the Redesign and Goal

Create a web-first educational experience that helps newcomers learn investment fundamentals through structured navigation and interactive content.

Including these pillars into the CIRO brand provided the opportunity to re-thinking the web experience on both CIRO's public facing website and employee internal site (intranet).

## Key Components

### Guided Learning Navigation

The guide is broken into digestible modules:

- Welcome to Canada
- Banking Basics
- Saving vs. Investing
- Understanding Risk
- Protecting Yourself from Fraud
- Additional Resources

Users can easily understand where they are, what they've completed, and what comes next.

### Interactive Saving vs. Investing Comparison

One of the guide's core concepts is explaining the difference between saving and investing. Rather than presenting information as static text, users can interact with a comparison component that visually highlights: Goals and Risk.

### Continued Learning Checkboxes

The guide transformed static, siloed PDFs into an interactive learning experience, allowing readers to explore related resources and bookmark topics of interest. Checkboxes track their selections and generate a personalized list of resources to revisit later.

The proposed site structure re-positioned important information including the organization's commitment to inclusion, accessibility and its mission on the main careers page. The main careers page was re-designed to identify dead-end points of exploration, leading online readers to either learn more about CIRO's EVPs or learn about open job opportunities.

This makes a foundational investing concept easier to understand.

## Technology

The redesigned experience would be built using:

- HTML
- CSS
- JavaScript
- React

React would be used to create reusable components for navigation, comparisons, and content interactions while maintaining a responsive and accessible user experience.

## Outcome

By transforming a static PDF into a dedicated web experience, the guide becomes:

- Easier to navigate
- More engaging
- Mobile-friendly
- More accessible
- Better aligned with modern learning behaviours

The redesign shifts investor education from document consumption to guided learning, helping newcomers build confidence in understanding investing in Canada.
